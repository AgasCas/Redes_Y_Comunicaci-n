PAN: Significa Red de Área Personal (Personal Area Network). Es un tipo de red de computadoras que conecta dispositivos electrónicos dentro del alcance inmediato de un usuario, generalmente a una distancia de unos pocos metros.
LAN: Es una red informática que conecta dispositivos dentro de un área geográfica limitada, como un hogar, oficina, escuela o un grupo de edificios cercanos. Las LAN permiten a los dispositivos comunicarse entre sí y compartir recursos, como impresoras y archivos, de manera eficiente.
MAN: Es una red informática que conecta varias redes de área local (LAN) dentro de una ciudad o área metropolitana. Es más grande que una LAN pero más pequeña que una red de área amplia (WAN). Las MANs permiten la comunicación y el intercambio de datos entre diferentes edificios, organizaciones o incluso partes de una misma ciudad.
WAN: Es una red de computadoras que conecta múltiples redes locales (LAN) a través de grandes distancias geográficas, como ciudades, países o incluso continentes.
